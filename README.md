# Top Down RPG
A Top-Down RPG computer game developed in the Unity engine, where the main feature is an intelligent AI companion that assists the player in battles.

## Technologies
*   **Engine:** Unity (2D)
*   **Programming Language:** C#
*   **IDE:** Visual Studio 2022

## Key Features
*   Player character control (movement, attack).
*   **AI Companion:** Follows the player, automatically attacks enemies targeted by the player.
*   Combat system with health bars and stamina (charge) bars.
*   Inventory system and artifact collection from chests.
*   NPC interaction (dialogue windows).
*   Save/Load system.
*   Intuitive pause menu, sound settings, and instructions.
